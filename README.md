# Hunza Valley Travel Guide

A simple, student-made travel guide to Hunza Valley in Gilgit-Baltistan, Pakistan. Browse local highlights and landmarks, or read practical trip-planning information in a responsive, multi-page website.

**Live website:** [Visit the Hunza Valley Travel Guide](https://u7lvk.github.io/Travel-Guide-to-Hunza/)

## Pages

- **Home** (`index.html`) — Introduction to Hunza Valley and highlights about its mountains, lakes, and culture.
- **Explore** (`explore.html`) — A gallery of landmarks including Passu Cones, Attabad Lake, Khunjerab Pass, Baltit Fort, Eagle's Nest, and Altit Fort.
- **Plan a Trip** (`plan.html`) — Seasonal travel information, a booking inquiry form, and frequently asked questions.

## Features

- Built with semantic HTML5 and CSS3; no JavaScript or build tools required.
- Shared stylesheet with responsive layouts, CSS Grid, and Flexbox.
- Accessible page structure, descriptive image text, and native HTML form controls.
- Landscape photography loaded from Unsplash, so an internet connection is needed to display the images.

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

Alternatively, serve the project locally from its root directory:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
